# Level 3 - Fullstack Todo

This is level 3 of the todo goat challenge.

The todo app finally has:

- a real backend
- a real database
- actual persistence
- a client-server architecture

localStorage is gone.

Nature is healing.

---

## What Changed From Level 2

Level 2 introduced component architecture with React.

Level 3 introduces:

- Fullstack architecture
- REST APIs
- Database persistence
- HTTP request lifecycle
- Client/server separation
- Backend state management
- Real CRUD operations

The frontend no longer owns the data.

The backend does.
